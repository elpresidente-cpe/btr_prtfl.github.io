# btr_prtfl.github.io

Personal portfolio website for GitHub Pages.

## Files

- `index.html`: Page content and sections
- `styles.css`: Visual design, layout, and responsive behavior
- `script.js`: Navigation toggle and reveal-on-scroll animation
- `CNAME`: Custom domain used by GitHub Pages

## Quick Customization

1. Replace hero/about text in `index.html`.
2. Update each project card with:
	- real title
	- short impact-focused description
	- live link and repo link
3. Update contact links and email in `index.html`.
4. Adjust colors in `styles.css` under `:root` variables.

## Publish

1. Commit and push to your `main` branch.
2. In GitHub repo settings, ensure Pages is enabled from the `main` branch root.
3. Since `CNAME` is included, your custom domain should stay connected.
