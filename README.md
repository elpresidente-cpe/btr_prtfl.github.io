# btr_prtfl.github.io

Personal portfolio website for Carl Joseph C. Bitor hosted on GitHub Pages.

## Overview

A modern, responsive portfolio showcasing computer engineering background, technical experience, projects, and skills. Built with clean HTML, CSS, and vanilla JavaScript for optimal performance.

## Sections

- **Hero**: Professional introduction with key focus areas
- **About**: Profile and core strengths
- **Experience**: Professional roles and internships
- **Education**: Degree, SHS, and high school background
- **Projects**: Featured capstone and academic projects
- **Skills**: Programming languages, frameworks, databases, and tools
- **Reference**: Professional contact reference
- **Contact**: Direct communication links

## Files

- `index.html`: Complete page structure and content
- `styles.css`: Responsive design, layout, color system, and animations
- `script.js`: Mobile navigation toggle and scroll reveal effects
- `CNAME`: Custom domain configuration

## Features

- ✨ Smooth reveal-on-scroll animations
- 📱 Fully responsive mobile-first design
- 🎨 Modern color palette and typography
- ⚡ Fast-loading single-page portfolio
- ♿ Semantic HTML for accessibility
- 🔗 Direct contact and social links

## Customization

1. Update contact information in the Contact section
2. Modify color palette in `styles.css` under `:root` CSS variables
3. Add GitHub project links in the Projects section
4. Update reference professional details
5. Adjust bio and core strengths in About section

## Publishing

1. Ensure all changes are committed to `main` branch
2. Push to GitHub: `git push origin main`
3. GitHub Pages will automatically build from the root directory
4. Your site will be live at your custom domain (configured via CNAME)

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Space Grotesk, Fraunces)
